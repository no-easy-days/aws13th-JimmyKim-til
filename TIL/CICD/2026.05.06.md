## 1. CD 툴의 기본, argoCD란?
- k8s 환경에서 `CD(Continuous Deployment or Delivery)`를 하기 위한 툴.
  > CNCF에서 k8s 구성 시 가장 권장하는 CD를 위한 tool이다. 용어 정리를 하면...
  > > `Continuous` = 자동 (트리거) + 여러번 반복
  > > 
  > > `Deployment` = 배포(kubectl apply -f `yaml 파일`)
  > > 
  > > `Delivery` = 이동(Manifest를 이동하여, **승인** 단계가 필요할 경우 사용)


- argoCD를 통한 배포 과정
 1. 소스코드 작성 & 수정하여 어플리케이션을 빌드
 2. 어플리케이션을 넣을 ***컨테이너 이미지를 빌드*** (이 과정이 들어가기 때문에, K8s 환경에서 권장되는 것이다)
 3. 컨테이너 이미지를 레지스트리에 `Push`
 4. **k8s 또는 Docker 환경에서 컨테이너 이미지를 `Pull`하여 배포(`kubectl apply -f` 또는 `docker run`)** → 이 과정이 자동으로 이뤄짐!


### argoCD는 git에 존재하는 manifest(yaml) 파일을 Kubernetes에 자동으로 적용시켜 주기 위한 툴일 뿐이다.
### Kubernetes 환경에서"만" 사용 가능하다! 다른 환경에서는 다른 툴을 활용하자.


## 2. argoCD 설치
- 지난 주 argoCD Toy Project에서 설치하는 과정과 완전히 동일함.

```bash
# ArgoCD 네임스페이스 생성 및 설치
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

# 설치 확인
kubectl get pods -n argocd -w
```


ArgoCD UI 접근을 위한 세팅 작업 (LoadBalancer로 노출):
```bash
kubectl patch svc argocd-server -n argocd \
  -p '{"spec": {"type": "LoadBalancer"}}'

# 초기 admin 패스워드 확인
kubectl get secret argocd-initial-admin-secret -n argocd \
  -o jsonpath='{.data.password}' | base64 -d

# URL 확인
kubectl get svc argocd-server -n argocd
```
