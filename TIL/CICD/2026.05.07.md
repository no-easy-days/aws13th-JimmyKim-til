## 1. GitHub Action

- 간단하다. github Repository에서 `Actions` 버튼 클릭하면 된다.


<img width="1285" height="227" alt="image" src="https://github.com/user-attachments/assets/18d5e80e-93f3-4de6-bb4d-dd78acb72b97" />


<br>


- Github Action 또한 `yaml` 파일 기반으로 동작한다. `.github/workflows` 디렉토리 밑에 `yaml` 파일로 작성하면 CI 기능이 활성화된다.
- 대상 Repository의 `Settings`로 접속하여 `Secrets and Variable` 옵션에서 암호화가 필요한 민감 정보가 담긴 값들을 세팅해줘야 한다. <br>
  - 예시1) AWS EKS 또는 ECR 연동을 위해서 `AWS configure` 명령어 입력 시 `AK`, `SAK` 필요
  - 예시2) 다른 레포지토리에 `git remote` 시, 필요에 따라 엑세스를 위한 `token` 필요
